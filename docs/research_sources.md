## Notes
- Timestamps without a timezone in source feeds are treated as IST.
- `empty` means reachable but nothing relevant in the window; `unavailable` carries the HTTP status or error as `reason`; `not_configured` means no verified endpoint or registry entry.
- Unverified / not done: no BSE sources; ICICIBANK IR extraction returns nothing; TCS and INFY IR pages never successfully fetched.

## Why Reddit `.json` fails without the API (17 Nov 2026)

Reddit's anonymous `.json` endpoints (`/r/<sub>/new.json`, `hot.json`, search `.json`) now require a login for every client: `www.reddit.com` answers 403 "blocked by network security" whatever the User-Agent, and `old.reddit.com` redirects to `/login/?reason=lor2`. Only RSS still works anonymously, and it is often rate-limited (429); `search.rss` sometimes returns 403. KAIROS therefore no longer probes `.json`.

The supported route is OAuth: set `REDDIT_CLIENT_ID` and `REDDIT_CLIENT_SECRET`. Without them the pipeline tries RSS; if every method fails, the run continues with Reddit marked `UNAVAILABLE` (provenance, an `evidence-unavailable` event, and a sentiment report with `data_source` `SOURCE_UNAVAILABLE`). The debate, research manager and trader are told sentiment was not assessed and must not treat it as neutral. Yahoo fundamentals and news stay fail-closed.
